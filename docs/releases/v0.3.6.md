# MarkitDown v0.3.6

本版本依据 [Microsoft MarkItDown](https://github.com/microsoft/markitdown) 0.1.6 的稳定能力扩展桌面转换模块，并统一菜单、资源管理器、拖放与系统文件打开入口的格式识别。Windows、macOS 与 Linux 安装包以及四个平台的转换模块均由 GitHub Actions 基于对应标签源码构建。

## 更新重点

### 转换能力扩展

- Office 与文档：PDF、DOCX、PPTX、XLSX、XLS。
- 网页与结构化文本：HTML、HTM、XHTML、CSV、JSON、JSONL、XML、RSS、Atom。
- 容器与电子书：ZIP、EPUB。
- 图片：JPG、JPEG、PNG；上游未返回文本时，应用生成本地图片引用、尺寸、颜色模式和可用 EXIF 信息。
- 音频与媒体：WAV、MP3、M4A、MP4；压缩媒体转写可能需要系统提供 FFmpeg。
- 其他：Outlook MSG、Jupyter Notebook、TXT、TEXT、Markdown。

旧式 Word `.doc` 和 PowerPoint `.ppt` 不在 Microsoft MarkItDown 0.1.6 的本地内置转换范围内，请先用 Office 或 LibreOffice 转存为 DOCX/PPTX。

### 打开文件

- “打开文件”、资源管理器、拖放、系统启动参数和“转换文档”菜单共用集中维护的格式清单。
- Markdown、源码、配置、日志和其他文本格式直接进入编辑器。
- PDF、Office、压缩包、电子书、图片、音频、MSG 与 Notebook 等二进制格式自动进入转换流程。
- 新增 TEXT、MDX、JSONL、XHTML 以及常见源码和配置文件后缀。

### 版本与质量

- 桌面应用：`0.3.6`
- 文档转换模块：`1.1.0`
- Microsoft MarkItDown：`0.1.6`
- 新增应用与转换模块版本一致性测试、格式目录同步测试和图片降级转换测试。

## 转换模块

主安装包不内置大型转换依赖。首次转换二进制文档时，可按提示在线安装，也可以在“设置 → 文档转换”中导入对应平台的离线 ZIP：

| 平台 | 转换模块 |
| --- | --- |
| Windows x86_64 | [下载 ZIP](https://github.com/zhcx/markitdown/releases/download/converter-v1.1.0/markitdown-converter-v1.1.0-x86_64-pc-windows-msvc.zip) |
| macOS Apple Silicon | [下载 ZIP](https://github.com/zhcx/markitdown/releases/download/converter-v1.1.0/markitdown-converter-v1.1.0-aarch64-apple-darwin.zip) |
| macOS Intel | [下载 ZIP](https://github.com/zhcx/markitdown/releases/download/converter-v1.1.0/markitdown-converter-v1.1.0-x86_64-apple-darwin.zip) |
| Linux x86_64 | [下载 ZIP](https://github.com/zhcx/markitdown/releases/download/converter-v1.1.0/markitdown-converter-v1.1.0-x86_64-unknown-linux-gnu.zip) |

Python 回退环境可执行：

```bash
python -m pip install 'markitdown[audio-transcription,docx,outlook,pdf,pptx,xls,xlsx]==0.1.6'
```

## 安装提示

- Windows 流水线当前明确构建无 Authenticode 签名安装包，SmartScreen 可能显示提示；请仅从本项目 Release 下载并核对来源。
- macOS 首次运行若被 Gatekeeper 阻止，可在“系统设置 → 隐私与安全性”中确认打开。
- AppImage 下载后执行 `chmod +x MarkitDown_0.3.6_amd64.AppImage` 再运行。
- MP3、M4A、MP4 转写依赖 FFmpeg；未安装时仍可使用其他文档转换功能。

## 隐私提示

普通文档、表格、网页、压缩包、电子书、图片元数据和 Notebook 转换均在本机执行。音频转写沿用 Microsoft MarkItDown 0.1.6 的可选 SpeechRecognition 实现，可能把音频发送至 Google Speech Recognition；请勿在不允许该传输的场景中转换敏感录音。
