# Zeditor v0.4.2

> 发布日期：2026-08-26

## 更新亮点

本次更新聚焦「编辑与预览体验打磨」，并让预览内链接行为更符合桌面应用直觉。

## 更新日志

- **分栏拖拽优化**：使用 Pointer Events 重写分隔条拖拽逻辑，跨分栏调整更顺滑、不再误触选中文本。
- **编辑 / 预览滚动体验**：增强编辑框与预览框的滚动浏览手感，长文档滚动更跟手、不跳变。
- **预览链接改为系统浏览器打开**：在预览框中点击链接不再在软件内打开，而是自动调用系统默认浏览器访问，避免打断写作上下文。

> 文档转换模块继续沿用 AnyDoc v1.2.0（本版本未变更转换引擎）。
