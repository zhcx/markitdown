# MarkitDown v0.3.5 — 文档转换器插件化重构

本版本对文档转换功能进行了根本性的架构重构：**将文档转换器从主安装包中剥离，改为按需下载的独立插件**。安装包体积显著减小，三平台转换体验首次实现统一。

## 更新日志

### 🔌 架构重构：文档转换器插件化

**核心变化：** 文档转换器不再内置于安装包中，而是作为独立插件，在用户首次导入非 Markdown 文件时按需下载。

- **安装包体积减少约 75%**：Windows 安装包从约 80 MB 降至约 15–25 MB
- **三平台体验统一**：Windows / macOS / Linux 首次转换时均自动提示下载插件，无需手动安装 Python
- **一次下载，永久使用**：转换器插件下载后在本地缓存，后续转换直接调用，无需重复下载
- **零开销**：只编辑 Markdown 的用户永远不会触发插件下载

### 🧩 转换器插件系统

- **新增** `converter` Rust 模块：管理插件生命周期（状态检查、下载校验、调用、卸载）
- **新增** `converter-latest.json` 远程清单：应用运行时自动获取最新版本的下载地址和 SHA256
- **新增** 设置面板「文档转换」标签页：可查看转换器安装状态、版本、卸载选项
- **新增** 安装引导对话框：首次拖入非 Markdown 文件时弹出，引导用户下载
- **SHA256 完整性校验**：下载后自动验证，确保二进制未被篡改
- 下载进度通过状态事件实时反馈到 UI

### 🏗️ 构建系统变更

- **新增** `converter-plugin/` 目录：包含转换器源码、PyInstaller 构建规范和本地构建脚本
- **新增** `.github/workflows/build-converter.yml`：三平台独立构建转换器插件的 CI 工作流
  - Windows x86_64、macOS Apple Silicon、Linux x86_64
  - 自动生成 SHA256 校验文件和版本清单
  - 推送 `converter-v*` 标签时自动发布到 Release
- **简化** 主应用构建流程：移除了 Python 安装、PyInstaller 编译、双阶段签名中的转换器环节
- **移除** `scripts/build-document-converter.ps1`（Windows 专用构建脚本，已由跨平台方案替代）
- **移除** `src-tauri/resources/document_converter.py` 和 `.spec`（不再随应用分发）

### 📦 体积变化

| 组件 | v0.3.4 | v0.3.5 | 变化 |
|------|--------|--------|------|
| Windows 安装包 | ~80 MB | ~20 MB | **−75%** |
| 转换器插件 | 内置 | ~200 MB（按需下载） | 可选 |
| 增量更新 | 每次重下转换器 | 仅更新应用 | **按需** |

### 🖥️ 转换器插件平台对照

| 平台 | 架构 | 下载文件 | 安装方式 |
|------|------|----------|----------|
| Windows | x86_64 | `markitdown-converter-{version}-x86_64-windows.zip` | 应用内自动下载解压 |
| macOS Apple Silicon | arm64 | `markitdown-converter-{version}-aarch64-darwin.tar.gz` | 应用内自动下载解压 |
| Linux | x86_64 | `markitdown-converter-{version}-x86_64-linux.tar.gz` | 应用内自动下载解压 |

> 转换器插件由 `.github/workflows/build-converter.yml` 独立构建并发布为 GitHub Release 资产，与应用主版本号解耦。

### 🐛 其他修复与优化

- 统一了转换器插件 CLI 协议：所有平台输出结构化的 JSON 状态信息
- 新增 `--version` 和 `--validate` 命令，便于调试和扩展
- 转换器插件入口脚本新增 `.csv` 格式支持（实验性）

## 从源码运行

```bash
# 安装前端依赖
npm install

# 开发模式
npm run tauri dev

# 构建发布
npm run tauri build
```

> 转换器插件作为独立二进制分发，从源码运行时不再需要安装 Python 和 markitdown 依赖。如需开发/测试转换器本身，请参见 `converter-plugin/` 目录下的说明。

## 安装提示

- **Windows：** 如果 SmartScreen 显示"未知发布者"，请先确认下载地址来自本 Release 页面，再选择"更多信息 → 仍要运行"。签名策略见 [Code Signing Policy](https://github.com/zhcx/markitdown/blob/main/CODE_SIGNING_POLICY.md)。
- **macOS：** 如果系统提示无法验证开发者，可在 Finder 中右键应用并选择"打开"，或在"系统设置 → 隐私与安全性"中确认打开。
- **Linux AppImage：** 下载后执行 `chmod +x MarkitDown_0.3.5_amd64.AppImage`，然后运行该文件。

## 文档转换使用说明

### 首次使用

1. 在编辑器中拖入一个 PDF、Word 或 Excel 文件
2. 应用检测到文档转换器未安装，自动弹出安装引导对话框
3. 点击「下载并安装」，应用将从 GitHub Release 下载对应平台的转换器插件
4. 下载完成后自动执行转换，文档内容以新标签页打开

> 下载大小约 200 MB（因平台而异），仅需下载一次。下载进度在对话框中实时显示。

### 管理转换器

- **设置 → 文档转换**：可查看当前转换器的安装状态和版本号
- **卸载**：在设置页中点击「卸载转换器」可释放磁盘空间，再次导入非 Markdown 文件时会重新引导下载

### 转换器插件独立更新

转换器插件与应用主程序版本解耦。当有新版本转换器发布时，应用会自动检测并在下一次转换时提示更新。转换器的构建状态和发布历史可通过 GitHub Actions 的 `Build Converter Plugin` 工作流查看。

## 发布验证
