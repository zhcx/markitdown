# MarkitDown v0.3.5

本版本新增**文档转换模块**系统，支持将 PDF、DOCX、XLSX、PPTX 等格式导入为 Markdown，并提供一键安装、离线导入和 Python 回退三种使用方式。同时优化了主题弹窗体验，统一错误提示风格。

## 更新日志

### 文档转换模块

- 新增按需安装的本地转换模块，支持 PDF、DOCX、XLSX、PPTX → Markdown 转换。
- 模块基于 Microsoft MarkItDown + PyInstaller 打包，首次使用时从 GitHub Release 一键安装。
- 支持离线导入：在"设置 → 文档转换"中可导入提前下载的 ZIP 包，无需网络。
- 支持导入自定义构建的离线模块包。
- Python 回退方案：安装 `markitdown` 库后自动调用，无需下载转换模块。
- Ed25519 发布清单签名验证，未配置 `CONVERTER_MANIFEST_PUBLIC_KEY` 时自动跳过。
- `MARKITDOWN_PYTHON` 环境变量可指定自定义 Python 路径。
- 模块安装后执行健康检查（优先 `--version-json`，降级为基本文件检查）。
- SHA-256 完整性校验、元数据格式验证、协议版本兼容性检查。

### 主题弹窗

- 转换模块缺失时弹出**主题确认安装弹窗**，替代原生 `window.confirm`。
- 转换失败时弹出**错误提示弹窗**，包含解决建议列表。
- 设置页卸载模块时改用**确认卸载弹窗**。
- 弹窗使用 `--ui-bg-overlay`、`--ui-border-strong` 等主题变量，自动适配所有明暗主题。

### 资源管理器（v0.3.4 延续）

- 右键菜单：复制、剪切、粘贴、新建文件/文件夹、重命名、删除、复制路径、在文件管理器中打开。
- 近期记录面板，保留天数可自定义。
- 文件树自动轮询刷新，切换文件时自动展开所在目录。

### 编辑与预览联动（v0.3.4 延续）

- 编辑器与预览区双向高亮定位，Markdown 标题生成稳定锚点。
- 统一滚动条宽度、滑块圆角、透明度与悬停状态。

- `module.json` — 模块元数据（格式、协议版本、SHA-256）

## 转换模块使用指南

### 首次安装

转换模块为按需下载的独立组件，首次导入非 Markdown 文件时自动提示安装：

1. 在资源管理器中右键 PDF/DOCX/XLSX/PPTX 文件 → "转换为 Markdown"。
2. 弹出**主题弹窗**，点击"立即安装"从 GitHub Release 下载对应平台组件。
3. 下载完成后自动安装并执行转换，结果以新标签页打开。

也可在**设置 → 文档转换**中手动操作：

| 操作 | 按钮 | 说明 |
| --- | --- | --- |
| 在线安装 | "在线安装" | 从 GitHub 下载并安装当前平台模块 |
| 导入离线包 | "导入离线包" | 选择本地 ZIP 包导入，适合无网络环境 |
| 检查更新 | "检查更新" | 查询是否有新版本可用 |
| 卸载模块 | "卸载模块" | 删除已安装的转换模块 |

### Python 回退方案

如果本机已安装 Python，更轻量的方式为：

```bash
python -m pip install 'markitdown[pdf,docx,pptx,xlsx]'
```

安装后无需下载转换模块，应用自动识别并调用 Python 回退。如需使用特定的 Python 环境（如 Conda 虚拟环境），在启动应用前设置环境变量：

```bash
# Windows (PowerShell)
$env:MARKITDOWN_PYTHON = "C:\Users\xxx\.conda\envs\myenv\python.exe"
markitdown

# macOS / Linux
MARKITDOWN_PYTHON="/opt/homebrew/bin/python3" ./markitdown
```

### 支持的转换格式

| 格式 | 说明 |
| --- | --- |
| PDF | 可携带文本的 PDF 文档 |
| DOCX | Word 文档 |
| XLSX | Excel 工作簿 |
| PPTX | PowerPoint 演示文稿 |

### 安全说明

- 文件转换**始终在本机处理**，不上传任何文件到服务器。
- 发布清单使用 Ed25519 签名（公钥编译期嵌入），确保下载来源可信。
- 模块包内可执行文件经过 SHA-256 完整性校验。
- 未设置 `CONVERTER_MANIFEST_PUBLIC_KEY` 时自动跳过 Ed25519 验证，适合自建测试。
- Windows 模块未进行 Authenticode 代码签名，但仍强制验证模块哈希。

### 故障排除

| 问题 | 解决方法 |
| --- | --- |
| 提示"转换模块缺失" | 安装 Python 回退（`pip install 'markitdown[...]'`），或在设置中安装模块 |
| 健康检查失败 | 重新导入或安装模块，确认文件权限正确 |
| Python 回退不生效 | 确认已执行 `pip install 'markitdown[pdf,docx,pptx,xlsx]'` |
| 转换结果为空 | 确认源文件包含可提取的文本内容 |
| SmartScreen 警告 | 点击"更多信息 → 仍要运行" |
