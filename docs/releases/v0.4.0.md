# Zeditor v0.4.0

本版本完成品牌焕新：全新应用图标与 GitHub 首页横幅，并延续云同步面板（WebDAV / S3 备份）的交互打磨与视觉优化。

## 主要变化

- 应用版本：`0.4.0`（与发布标签 `v0.4.0` 一致）
- 转换模块版本：`1.2.0`（与 v0.3.7 + 保持一致，本版本未变更转换引擎）

### 品牌与图标

- **全新应用图标**：以蓝色渐变 `Z` 标识替换旧图标，通过 Tauri 官方 `tauri icon` 重新生成全套平台资源（Windows `.ico` / `.msi` 资源、macOS `.icns`、iOS / Android 全尺寸、Store Logo 等）。
- **GitHub 首页横幅**：`README.md` 顶部插图替换为新的产品横幅（`docs/banner.png`），展示编辑器界面与多色主题。

### 云同步面板修复（延续自 v0.3.9）

- **启用状态显示**：已配置 WebDAV / S3 时，状态栏弹窗正确显示「就绪 / 同步中 / 已同步」等状态，不再误报「未启用」。
- **滑动开关样式统一**：底部状态栏云同步弹窗的开关改为与「设置」页一致的药丸形，并修复全局 `button` 圆角规则覆盖问题。
- **未配置拦截**：WebDAV / S3 未配置时点击开关，先关闭面板再跳转「设置 → WebDAV 备份 / S3 云同步」。
- **设置按钮层级**：云同步面板内「设置」按钮点击后先关闭面板，避免其 `z-index: 99999` 遮罩挡住设置页导致无法点击。
- **历史版本打开**：「浏览全部备份」列表中，版本支持「打开」（新标签页）与「另存为」，文档行双击打开最新版本。

### 视觉优化（延续自 v0.3.9）

- **面板入场动画**：云同步面板改用弹性 `cloudPanelIn`（上移 + 缩放）入场；历史弹窗使用 `fadeInUp`，风格呼应。
- **供应商卡片反馈**：悬停上浮加阴影，未启用卡片降饱和与透明度，卡片头部渐变增强层次。
- **同步状态指示**：同步中圆点叠加脉冲光晕动画。
- **图标统一**：历史弹窗关闭按钮由文字 `✕` 改为 SVG 图标，与云同步面板一致。

## 支持格式

与 v0.3.9 一致：DOC、DOCX、DOCM、PPT、PPS、POT、PPTX、PPTM、PPSX、PPSM、XLS、XLSX、XLSM、XLSB、ODT、ODS、ODP、RTF、EPUB、CSV 和文本型 PDF。

扫描型 PDF 需要 OCR 引擎；图片、音频、Outlook MSG、JSON/XML 信息流、ZIP 和 Jupyter Notebook 不在本版本 AnyDoc 转换模块范围内。

## 本地构建

### 构建环境

- Node.js（v22.6+ 验证通过）、npm
- Rust 工具链（cargo / rustc，v1.85+ 验证通过）
- Tauri CLI 2.x（`@tauri-apps/cli`，v2.11 验证通过）
- Windows 需安装 WiX Toolset（MSI）与 NSIS（setup.exe）

### 构建应用安装包

```powershell
cd d:/Documents/code/zeditor
npm install            # 首次或依赖变更时
npm run tauri build
```

产物位于：

- `src-tauri/target/release/bundle/msi/Zeditor_0.4.0_x64_en-US.msi`
- `src-tauri/target/release/bundle/nsis/Zeditor_0.4.0_x64-setup.exe`

> v0.4.0 安装包体积约 7–8 MB，转换模块仍为按需下载的独立引擎。

### 重建图标资源（如需替换品牌图标）

将新的方形源图（建议 ≥ 1024×1024，透明背景）放入 `src-tauri/icon-source.png`，执行：

```powershell
npm run tauri -- icon src-tauri/icon-source.png
```

该命令会重新生成 `src-tauri/icons/` 下全部平台图标（Windows / macOS / iOS / Android / Store）。

### 构建转换模块离线包（v1.2.0）

使用项目自带脚本 `scripts/prepare-converter-package.mjs`（与 CI `converter.yml` 逻辑一致）先生成 `module.json` 并复制可执行文件，再打包为 ZIP：

```powershell
cd d:/Documents/code/zeditor
# 1) 先确保转换模块已编译
cargo build --manifest-path converter/Cargo.toml --release --locked

# 2) 生成打包目录（含 module.json + document_converter.exe）
node scripts/prepare-converter-package.mjs `
  "converter/target/release/document_converter.exe" `
  "1.2.0" `
  "x86_64-pc-windows-msvc" `
  "converter-package-v120"

# 3) 打包为可导入的离线包
Compress-Archive -Path converter-package-v120/* `
  -DestinationPath "zeditor-converter-v1.2.0-x86_64-pc-windows-msvc.zip" -Force
```

离线包 ZIP 命名需与 CI 产物一致：`zeditor-converter-v{version}-{target}.zip`。
导入方式：安装 Zeditor → 设置 → 文档转换 → 导入离线包 → 选中该 ZIP。

> 当前未配置 `CONVERTER_MANIFEST_PUBLIC_KEY`，离线包无需 `module.sig` 即可导入（签名验证自动跳过）。
