# MarkitDown v0.3.4

本版本新增 Claude Code、Codex 和 OpenCode 本地 Agent（Beta），完善 AI/Agent 会话历史，并集中优化编辑器右键菜单、编辑与预览联动、滚动条、字号同步和设置交互。Windows、macOS 与 Linux 安装包由 GitHub Actions 基于 v0.3.4 标签源码构建。

## 更新日志

### 本地 Agent（Beta）

- 在 AI 侧边栏中切换 Claude Code、Codex 或 OpenCode，复用本机 CLI 登录状态与默认模型。
- 支持流式任务、工具调用状态、逐次命令审批和仅当前会话完全允许。
- Git 仓库任务默认使用临时 worktree 隔离变更，非 Git 目录可在明确授权后直接写入当前目录。
- 改进 Windows CLI 可执行文件发现与进程启动，避免命令行窗口弹出并修复 Claude Code `exit code: 255` 类路径问题。
- 修正 Agent 设置在窄窗口中的溢出、状态提示排版和重复错误消息。

### AI 与 Agent 会话

- AI 对话新增“新建对话”和历史记录按钮，可恢复之前的问答内容。
- Agent 新建会话后仍可查看历史记录，并按规范化后的工作目录路径关联会话。
- 统一 AI 与 Agent 的模型、推理强度、权限和文件上下文控件。

### 编辑器与菜单

- 右键菜单新增 AI 润色与 AI 翻译，翻译结果复用现有对照浮窗和应用确认流程。
- “复制为”支持 HTML 和纯文本，并根据窗口空间自动选择向左或向右展开。
- 增加导出 PDF、Word、HTML、插入图片和在文件夹中显示等快捷操作。
- 浮动编辑栏压缩到更适合编辑区的宽度，常用操作保持完整。

### 编辑与预览联动

- 点击或移动到编辑器某一行时，编辑器当前行与预览区对应 Markdown 内容同步高亮。
- 引用、列表、表格等复合内容按完整语义块高亮，包含引用边线和区块内全部正文。
- 点击编辑器内容时，预览区自动滚动到对应部分，并与当前编辑行保持水平对齐。
- 点击预览内容时，编辑器自动定位光标和源码行；程序化滚动不会造成双向同步抖动。

### 滚动条、字号与主题

- 编辑器、预览区和资源管理器统一滚动条宽度、滑块圆角、透明度和悬停状态。
- 移除 Monaco 编辑器右侧多余的概览标记，使滚动显示与预览区一致。
- 调整字号时编辑器和预览区实时同步；保存设置改为异步持久化，减少界面停顿。
- 移除 Inkwell 明暗主题，保留更一致的主题体系。

## 安装提示

- **Windows：** 如果 SmartScreen 显示“未知发布者”，请先确认下载地址来自本 Release 页面，再选择“更多信息 → 仍要运行”。签名策略见 [Code Signing Policy](https://github.com/zhcx/markitdown/blob/main/CODE_SIGNING_POLICY.md)。
- **macOS：** 如果系统提示无法验证开发者，可在 Finder 中右键应用并选择“打开”，或在“系统设置 → 隐私与安全性”中确认打开。
- **Linux AppImage：** 下载后执行 `chmod +x MarkitDown_0.3.4_amd64.AppImage`，然后运行该文件。
