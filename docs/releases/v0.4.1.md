# Zeditor v0.4.1

本版本聚焦资源管理器（侧边栏文件树）的三项体验修复：目录层级缩进、时间线标题单行显示，以及工作区一级目录的关闭按钮。修复内容已在 `perf/split-pane-scroll` 分支验证后合入主线。

## 主要变化

- 应用版本：`0.4.1`（与发布标签 `v0.4.1` 一致）
- 转换模块版本：`1.2.0`（本版本未变更转换引擎）

### 资源管理器

- **目录层级缩进**：工作区根目录下的子级项目此前与根目录标题对齐，二级及更深目录缩进不明显。现调整树节点缩进公式（基准 8px → 16px，每级 14px → 20px），一级、二级、三级目录逐级缩进，层级一目了然。
- **时间线标题单行**：「时间线」区块标题在文件名过长时会发生换行、挤压计数徽标。现固定「时间线」标签单行显示，文件名弹性占位并以省略号截断，计数徽标不再被挤走。
- **一级目录关闭按钮**：
  - 鼠标悬停在工作区根目录标题上时显示 `×` 关闭按钮，样式与打开的编辑器标签页关闭按钮一致；
  - 右键菜单新增「关闭文件夹」入口；
  - 关闭一级目录会将其从工作区移除（不删除磁盘内容），同时收起并清理该目录下所有已展开子文件夹的状态，并从持久化的根目录列表中移除；
  - 关闭后 30 秒内，不会因当前打开文件位于被关闭目录之下而把其子目录自动重新添加为独立根目录。
- **刷新保留展开内容**：自动刷新（轮询）与手动刷新改为合并已懒加载的子目录 children（新增 `mergeLoadedChildren` / `replaceNodeChildrenMerged` 工具函数并有单元测试覆盖），不再把已展开的二级、三级目录清空成「空文件夹」。

### 版本源对齐

- 修正 `package.json` 版本滞后的问题，使其与 `tauri.conf.json`、`Cargo.toml` 保持一致；发布合规测试（`tests/releaseCompliance.test.ts`）同步锁定新版本号。

## 支持格式

与 v0.4.0 一致：DOC、DOCX、DOCM、PPT、PPS、POT、PPTX、PPTM、PPSX、PPSM、XLS、XLSX、XLSM、XLSB、ODT、ODS、ODP、RTF、EPUB、CSV 和文本型 PDF。

扫描型 PDF 需要 OCR 引擎；图片、音频、Outlook MSG、JSON/XML 信息流、ZIP 和 Jupyter Notebook 不在本版本 AnyDoc 转换模块范围内。

## 平台安装包

应用安装包由 `v0.4.1` 标签触发 GitHub Actions 构建：

| 平台 | 资产 | 架构 |
| --- | --- | --- |
| Windows | `Zeditor_0.4.1_x64-setup.exe`、`Zeditor_0.4.1_x64_en-US.msi` | x86_64 |
| macOS（Apple Silicon） | `Zeditor_0.4.1_aarch64.dmg`、`Zeditor_aarch64.app.tar.gz` | aarch64 |
| macOS（Intel） | `Zeditor_0.4.1_x64.dmg`、`Zeditor_x64.app.tar.gz` | x86_64 |
| Linux | `Zeditor_0.4.1_amd64.deb`、`Zeditor-0.4.1-1.x86_64.rpm`、`Zeditor_0.4.1_amd64.AppImage` | x86_64 |

> 说明：安装包文件名中的版本号为 `0.4.1`，与 `Cargo.toml` 及发布标签 `v0.4.1` 一致。

转换模块沿用 `converter-v1.2.0`（本版本未变更，无需重新下载）：

| 平台 | 资产 |
| --- | --- |
| Windows x86_64 | `zeditor-converter-v1.2.0-x86_64-pc-windows-msvc.zip` |
| macOS Apple Silicon | `zeditor-converter-v1.2.0-aarch64-apple-darwin.zip` |
| macOS Intel | `zeditor-converter-v1.2.0-x86_64-apple-darwin.zip` |
| Linux x86_64 | `zeditor-converter-v1.2.0-x86_64-unknown-linux-gnu.zip` |

模块安装前会校验清单、SHA-256、可选 Ed25519 签名、目标平台和 AnyDoc 引擎标识。Windows 模块目前未启用 Authenticode 签名。

## 隐私

AnyDoc 转换在本机执行，不上传文档。资源管理器关闭文件夹操作仅影响工作区展示，不删除磁盘内容。
