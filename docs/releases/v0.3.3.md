# MarkitDown v0.3.3

本版本聚焦编辑器快捷工具、浮动编辑栏、搜索汉化、预览同步滚动和底部 AI 入口重整。Windows、macOS 与 Linux 安装包由 GitHub Actions 基于 v0.3.3 源码构建。

## 更新日志

### 编辑器快捷工具栏

- 固定编辑栏采用更紧凑的图标工具带风格，并随浅色/深色主题自动切换。
- 工具栏会根据当前编辑框宽度动态显示按钮，超出部分进入末尾“更多”菜单。
- 去除快捷按钮分类中文标题，改用竖线分隔功能分组，减少编辑区占用。
- 取消快捷按钮栏默认固定显示，用户可在设置中选择是否常驻显示。

### 浮动编辑栏

- 选中文字后以浮动快捷栏显示常用编辑功能。
- 浮动栏根据当前编辑框宽度尽量显示更多功能，剩余功能折叠到“更多”菜单。
- 修复浅色主题下部分浮动栏图标显示为黑色的问题。
- 修复第一次显示浮动栏后，再次选中其他文字不再显示的问题。

### `/` 命令面板

- 扩充行首 `/` 菜单，补充常用编辑、插入、表格、代码块、媒体、公式、分隔线和文档结构命令。
- 增加 AI 写作相关入口，减少固定工具栏隐藏后的操作空白。
- 保持中文/英文搜索、键盘导航、鼠标选择、`Enter` / `Tab` 插入和 `Esc` 关闭。

### 搜索、本地化与主题

- 保留 Monaco Editor 原生搜索能力。
- 将搜索栏提示、结果、替换、大小写、正则、整词、上下跳转等界面文案汉化为简体中文。
- 搜索栏颜色、边框、阴影和按钮状态调整为与当前主题一致。

### 编辑区与预览区同步

- 工具栏打开或关闭时，预览区高度会实时跟随编辑区变化。
- 优化编辑区文字与预览区文字的行高、顶部内边距和同步滚动锚点。
- 修复编辑器滚动到最底部时，预览区末尾仍有一段内容无法自动显示的问题。
- 缓存滚动锚点并使用更轻量的查找逻辑，降低长文浏览时的卡顿感。

### AI 底部菜单

- 底部 AI 菜单移除“AI 对话”按钮，对话入口保留在左侧功能栏。
- “校对文字”独立列在底部菜单栏，点击即可对选中文本或全文启动校对。
- “伴写”独立显示开启/关闭状态，点击可选择写作风格。
- AI 菜单中移除伴写相关设置，保留重写、翻译、摘要、大纲、操作模式和 AI 设置入口。

## 安装提示

- **Windows：** 如果 SmartScreen 显示“未知发布者”，请先确认下载地址来自本 Release 页面，再选择“更多信息 → 仍要运行”。签名策略见 [Code Signing Policy](https://github.com/zhcx/markitdown/blob/main/CODE_SIGNING_POLICY.md)。
- **macOS：** 如果系统提示无法验证开发者，可在 Finder 中右键应用并选择“打开”，或在“系统设置 → 隐私与安全性”中确认打开。
- **Linux AppImage：** 下载后执行 `chmod +x MarkitDown_0.3.3_amd64.AppImage`，然后运行该文件。
