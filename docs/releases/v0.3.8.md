# Zeditor v0.3.8

本版本聚焦稳定性与体验打磨：精简主题体系、修复菜单栏交互、并修复此前代码审查中发现的性能、资源泄漏与安全隐患。

## 主要变化

- 应用版本：`0.3.8`
- 转换模块版本：`1.2.0`（与 v0.3.7 保持一致，本版本未变更转换引擎）

### WebDAV 文档备份（新功能）

本版本新增**桌面版单向 WebDAV 自动备份**：

- **配置**：在「设置 → WebDAV 备份」中填写服务器地址、用户名、密码 / 应用密码与远端根目录（默认 `/Zeditor`），支持测试连接（写读删探针）。
- **单向同步**：本地保存成功后自动异步上传；云端失败**不会**使本地保存失败，也不会把文档标记为未保存。
- **当前副本与历史**：远端保留一份最新副本，并按内容 SHA-256 去重保留最近 **20 个不同内容版本**。重复保存相同内容不会新增版本。
- **状态栏**：显示未启用 / 等待同步 / 正在同步 / 已同步 / 同步失败五种状态；点击非错误状态打开当前文档历史，点击失败状态立即重试并显示错误详情。
- **失败恢复**：失败任务持久化到本地队列，应用重启、下次保存或手动重试时恢复；凭据变更后重试使用最新设置。
- **历史下载**：状态栏与「浏览全部备份」均支持按版本「另存为」，下载前在 Rust 侧校验 SHA-256，不修改当前文档。
- **隐私**：仅在你启用后，向**你自己配置的服务器**发送已保存内容、相对路径、时间戳、哈希与版本清单；凭据仅存于本地设置文件，Zeditor 维护者不接收这些流量。

### 主题体系精简

- 移除 Claude（Light/Dark）与 Notion（Light/Dark）共四套主题，**仅保留 VS Code 深 / 浅两套配色**。
- 将保留的配色重命名为 **「深色主题」** 与 **「浅色主题」**，与之对应的「功能 → 主题」菜单、设置面板与界面文案同步更新。
- 在保留既有配色基调的前提下统一色彩饱和度与对比度，精简冗余颜色变量，优化语法高亮层级（统一为 6 级），提升编辑器各区域（侧边栏、状态栏、输入框、下拉菜单等）风格协调性。

### 菜单栏交互修复

- 修复鼠标移出时菜单过快收回、导致无法点击目标菜单的问题：收回延迟由 150ms 调整为 350ms，并支持悬停进入邻近区域时取消收回。
- 修复二级子菜单因触发区与子菜单之间存在 4px 间隙而难以触达的问题：在菜单与子菜单之间加入透明桥接区域，移除导致层叠错位的 CSS 选择器冲突，避免定时器泄漏导致的误关闭。

### 质量加固（代码审查修复）

- 后端（Rust）：修复 PDF 导出浏览器池资源泄漏（`browser_pool` 改用可失效的 `Mutex<Option<Arc<Browser>>>`）；为 PDF 标签增加 `TabGuard` RAII 守卫与就绪轮询；修复 `commands.rs` 文件命令授权根、符号链接遍历、并发下载竞态；`converter.rs` 增加 SHA-256 缓存与临时文件清理守卫；Agent 模块增加持久化节流、事件上限、SSE 首包格式校正、原子写入与命令审批规范化；`agent/git.rs` 采用 `-z` 解析并减少 git 调用（N+1 → 3 次）。
- 前端：收紧 Tauri 内容安全策略（CSP 由 `null` 改为严格策略）；主题引导脚本外置为 `theme-boot.js`；修复菜单更新流程保存脏文档后再执行安装收尾的逻辑。
- 安全：文件写入校验授权根、模块清单签名校验告警收敛；Web 搜索开发期代理注释化。

## 支持格式

与 v0.3.7 一致：DOC、DOCX、DOCM、PPT、PPS、POT、PPTX、PPTM、PPSX、PPSM、XLS、XLSX、XLSM、XLSB、ODT、ODS、ODP、RTF、EPUB、CSV 和文本型 PDF。

扫描型 PDF 需要 OCR 引擎；图片、音频、Outlook MSG、JSON/XML 信息流、ZIP 和 Jupyter Notebook 不在本版本 AnyDoc 转换模块范围内。

## 本地构建

### 构建环境

- Node.js（v22.6+ 验证通过）、npm
- Rust 工具链（cargo / rustc，v1.85+ 验证通过）
- Tauri CLI 2.x（`@tauri-apps/cli`，v2.11 验证通过）
- Windows 需安装 WiX Toolset（MSI）与 NSIS（setup.exe）

### 构建应用安装包

```powershell
cd d:/Documents/code/zeditor
npm install            # 首次或依赖变更时
npm run tauri build
```

产物位于：

- `src-tauri/target/release/bundle/msi/Zeditor_0.3.8_x64_en-US.msi`
- `src-tauri/target/release/bundle/nsis/Zeditor_0.3.8_x64-setup.exe`

> v0.3.8 安装包体积约 7–8 MB，转换模块仍为按需下载的独立引擎。

### 构建转换模块离线包（v1.2.0）

使用项目自带脚本 `scripts/prepare-converter-package.mjs`（与 CI `converter.yml` 逻辑一致）先生成 `module.json` 并复制可执行文件，再打包为 ZIP：

```powershell
cd d:/Documents/code/zeditor
# 1) 先确保转换模块已编译
cargo build --manifest-path converter/Cargo.toml --release --locked

# 2) 生成打包目录（含 module.json + document_converter.exe）
node scripts/prepare-converter-package.mjs `
  "converter/target/release/document_converter.exe" `
  "1.2.0" `
  "x86_64-pc-windows-msvc" `
  "converter-package-v120"

# 3) 打包为可导入的离线包
Compress-Archive -Path converter-package-v120/* `
  -DestinationPath "zeditor-converter-v1.2.0-x86_64-pc-windows-msvc.zip" -Force
```

离线包 ZIP 命名需与 CI 产物一致：`zeditor-converter-v{version}-{target}.zip`。
导入方式：安装 Zeditor → 设置 → 文档转换 → 导入离线包 → 选中该 ZIP。

> 当前未配置 `CONVERTER_MANIFEST_PUBLIC_KEY`，离线包无需 `module.sig` 即可导入（签名验证自动跳过，详见 `windows-code-signing.md` / 报告风险点 R2）。
