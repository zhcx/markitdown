# MarkitDown v0.3.1

本版本重点升级文件管理体验与 AI 对话面板，并修复 Windows 标题栏窗口交互问题。建议所有旧版本用户升级。

## Windows 标题栏热修复（2026-07-20）

- 修复自定义标题栏偶发无法拖动的问题。
- 修复点击标题栏时窗口偶发最小化或窗口状态异常的问题。
- 修复窗口最小化后，点击 Windows 任务栏中的 MarkitDown 图标偶发无法恢复界面的问题。
- 标题栏统一使用 Tauri 原生拖拽与双击处理，移除重复的手动窗口操作，避免 Windows 窗口消息竞态。
- 新增标题栏窗口交互回归测试。

## 更新亮点

### 文件管理器图标升级

- 参考 VS Code 重新设计文件类型图标，覆盖常见编程语言、配置文件、文档、媒体、压缩包与特殊文件。
- 改进 `README`、`.env`、`.gitignore`、Dockerfile 等特殊文件名识别。
- 源码和配置文件现在可直接以文本方式打开。

### AI 对话界面优化

- 重构 AI 对话面板头部，优化服务商、模型选择与工作区范围提示。
- 改进长模型名称和窄侧栏布局。

### 稳定性、安全性与性能

- 修复工作区批量替换、设置并发保存和标签页状态清理问题。
- 改进文件夹扫描与图片上传性能。
- 加强 AI 回复、Markdown 导出、搜索结果、附件和图片处理的安全防护。
- Windows 安装包增加 Markdown 文件关联、专用图标和离线文档转换器。

## 安装提示

- **Windows：** 如果 SmartScreen 显示“未知发布者”，请先确认下载地址来自本 Release 页面，再选择“更多信息 → 仍要运行”。签名策略见 [Code Signing Policy](https://github.com/zhcx/markitdown/blob/main/CODE_SIGNING_POLICY.md)。
- **macOS：** 如果系统提示无法验证开发者，可在 Finder 中右键应用并选择“打开”，或在“系统设置 → 隐私与安全性”中确认打开。
- **Linux AppImage：** 下载后执行 `chmod +x MarkitDown_0.3.1_amd64.AppImage`，然后运行该文件。
