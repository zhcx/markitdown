# Zeditor v0.3.9

本版本聚焦云同步面板（WebDAV / S3 备份）的交互与视觉打磨：修复多处 UI 缺陷，并统一面板设计语言。

## 主要变化

- 应用版本：`0.3.9`
- 转换模块版本：`1.2.0`（与 v0.3.7 / v0.3.8 保持一致，本版本未变更转换引擎）

### 云同步面板修复

- **启用状态显示**：已配置 WebDAV / S3 时，状态栏弹窗中正确显示「就绪 / 同步中 / 已同步」等状态，不再误报「未启用」（phase 归一化：已启用且后端 phase 为 `disabled` 时按 `idle` 处理）。
- **滑动开关样式统一**：底部状态栏云同步弹窗的开关改为与「设置」页一致的药丸形。根因为全局 `.app :is(button){border-radius:3px!important}` 规则覆盖了单类选择器，已通过提升选择器优先级（`.cloud-panel .cloud-switch`，0,2,0）并全属性加 `!important`、`appearance:none` 解决；关闭遮罩 z-index 冲突，确保面板关闭后再打开设置页。
- **未配置拦截**：WebDAV / S3 未配置时点击开关，先关闭云同步面板再跳转「设置 → WebDAV 备份 / S3 云同步」，不再在弹窗内直接显示「就绪」。
- **设置按钮层级**：云同步面板内「设置」按钮点击后先关闭面板，避免其 `z-index: 99999` 遮罩挡住设置页导致无法点击。
- **历史版本打开**：「浏览全部备份」列表中，版本支持「打开」（下载并以新标签页打开）与「另存为」两种方式，文档行双击打开最新版本。

### 视觉优化

- **面板入场动画**：云同步面板改用弹性 `cloudPanelIn`（上移 + 缩放）入场，替代纯淡入；历史弹窗使用 `fadeInUp`，风格呼应。
- **供应商卡片反馈**：卡片悬停上浮并加阴影，未启用卡片降低饱和与透明度；卡片头部改用渐变背景增强层次。
- **同步状态指示**：同步中圆点叠加脉冲光晕动画，状态更醒目。
- **图标统一**：历史弹窗关闭按钮由文字 `✕` 改为 SVG 图标，与云同步面板关闭按钮一致。

## 支持格式

与 v0.3.8 一致：DOC、DOCX、DOCM、PPT、PPS、POT、PPTX、PPTM、PPSX、PPSM、XLS、XLSX、XLSM、XLSB、ODT、ODS、ODP、RTF、EPUB、CSV 和文本型 PDF。

扫描型 PDF 需要 OCR 引擎；图片、音频、Outlook MSG、JSON/XML 信息流、ZIP 和 Jupyter Notebook 不在本版本 AnyDoc 转换模块范围内。

## 本地构建

### 构建环境

- Node.js（v22.6+ 验证通过）、npm
- Rust 工具链（cargo / rustc，v1.85+ 验证通过）
- Tauri CLI 2.x（`@tauri-apps/cli`，v2.11 验证通过）
- Windows 需安装 WiX Toolset（MSI）与 NSIS（setup.exe）

### 构建应用安装包

```powershell
cd d:/Documents/code/zeditor
npm install            # 首次或依赖变更时
npm run tauri build
```

产物位于：

- `src-tauri/target/release/bundle/msi/Zeditor_0.3.9_x64_en-US.msi`
- `src-tauri/target/release/bundle/nsis/Zeditor_0.3.9_x64-setup.exe`

> v0.3.9 安装包体积约 7–8 MB，转换模块仍为按需下载的独立引擎。

### 构建转换模块离线包（v1.2.0）

使用项目自带脚本 `scripts/prepare-converter-package.mjs`（与 CI `converter.yml` 逻辑一致）先生成 `module.json` 并复制可执行文件，再打包为 ZIP：

```powershell
cd d:/Documents/code/zeditor
# 1) 先确保转换模块已编译
cargo build --manifest-path converter/Cargo.toml --release --locked

# 2) 生成打包目录（含 module.json + document_converter.exe）
node scripts/prepare-converter-package.mjs `
  "converter/target/release/document_converter.exe" `
  "1.2.0" `
  "x86_64-pc-windows-msvc" `
  "converter-package-v120"

# 3) 打包为可导入的离线包
Compress-Archive -Path converter-package-v120/* `
  -DestinationPath "zeditor-converter-v1.2.0-x86_64-pc-windows-msvc.zip" -Force
```

离线包 ZIP 命名需与 CI 产物一致：`zeditor-converter-v{version}-{target}.zip`。
导入方式：安装 Zeditor → 设置 → 文档转换 → 导入离线包 → 选中该 ZIP。

> 当前未配置 `CONVERTER_MANIFEST_PUBLIC_KEY`，离线包无需 `module.sig` 即可导入（签名验证自动跳过，详见 `windows-code-signing.md` / 报告风险点 R2）。
