# Zeditor v0.4.3

> 发布日期：2026-09-06

## 更新亮点

本版本系统修复了 WebView2 下 Monaco 编辑器输入期间文字消失、折行行高失效以及首行上方字符闪现的问题，并同步完善输入法设置和发布链路。

## 更新日志

- **修复编辑器正文消失**：修复生产包 CSP 自动注入 nonce 后，Monaco 动态行样式被拦截，导致视图行位置和高度归零的问题。
- **修复首行上方闪字**：移除会遮盖 Monaco 输入层和折行内容的顶部遮罩，恢复编辑器原生行布局。
- **输入法引擎设置持久化**：Rust 设置结构现在保存 `input_engine`，原生 EditContext 默认启用，传统 textarea 作为兼容回退；设置保存后即时切换。
- **清理输入层样式冲突**：应用全局表单样式不再覆盖 Monaco 的输入载体、组合态选区与几何属性。
- **发布质量门禁**：补充 CSP 和 WebView2 行几何验证脚本，覆盖短文本、折行组合、取消、上屏、撤销、退格、中英混输和换段。
