# Zeditor v0.4.4

> 发布日期：2026-09-06

## 更新亮点

本版本集中修复编辑器使用过程中的数据安全问题，覆盖多标签撤销、AI 异步操作、保存与关闭竞态、自动保存，以及编辑器设置持久化。

## 更新日志

- **独立标签编辑状态**：每个标签拥有自己的 Monaco 模型和撤销栈，切换标签不再串用撤销记录。
- **AI 结果安全回写**：AI 请求返回时核对标签 ID 和文档内容，切换文档或继续编辑后自动拒绝过期结果。
- **AI 撤销保护**：只有文档仍保持 AI 应用后的内容时才允许整轮恢复，后续手写内容不会被覆盖。
- **保存队列**：并发保存按顺序执行，单次磁盘写入失败不会污染后续保存；保存错误会传递到界面。
- **关闭与更新保护**：保存期间取消关闭、产生新修改或出现新未保存标签时保持窗口打开；软件更新会先检查并保存全部未保存标签。
- **自动保存**：按照设置周期保存已有路径且已修改的标签，未命名文档继续等待用户选择保存路径。
- **设置持久化**：输入法引擎和固定编辑快捷栏等编辑器设置在桌面端 JSON 中完整保存。
- **依赖审计**：更新 browserslist 与 DOMPurify，修复发布质量门禁中的高危依赖告警。
