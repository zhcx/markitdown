# MarkitDown v0.3.2

本版本新增简体中文、繁体中文和英文界面，修正编辑器右键菜单语言，同时包含行首 `/` Markdown 快捷命令面板和 Windows 标题栏修复。本页的 Windows、macOS 与 Linux 安装包均已由最新 v0.3.2 源码重新构建。

## 更新日志

### 多语言界面与中文右键菜单

- 支持简体中文、繁体中文和英文界面。
- 首次启动时识别 `zh-CN` / `zh-SG`、`zh-TW` / `zh-HK` / `zh-MO` / `zh-Hant` 和 `en-*` 系统语言。
- 可在“设置 → 外观 → 界面显示语言”中手动切换，选择会持久保存。
- 用支持多语言的应用菜单替换 Monaco 默认英文右键菜单，支持撤销、重做、剪切、复制、粘贴和全选。
- 修正主题、图床、搜索深度和帮助页等可见界面中遗留的功能性英文。

### Markdown 快捷命令面板

- 在编辑器行首输入 `/`，即可打开类似 Notion 的命令窗口。
- 输入关键词可筛选命令，例如 `/h2`、`/table`、`图片` 或 `formula`。
- 支持一级/二级/三级标题、引用、无序列表、有序列表、任务列表、代码块、表格、图片、链接、行内公式、公式块、脚注、分割线和 Mermaid 流程图。
- 支持鼠标选择、`↑` / `↓` 导航、`Enter` / `Tab` 插入、`Esc` 关闭。
- 插入后自动将光标放置在占位文本或可继续输入的位置。
- 面板会根据光标位置自动定位，在窗口边缘自动缩短并提供滚动。

### Windows 窗口交互修复

- 修复自定义标题栏偶发无法拖动的问题。
- 修复点击标题栏时窗口偶发最小化或窗口状态异常的问题。
- 修复窗口最小化后，点击 Windows 任务栏中的 MarkitDown 图标偶发无法恢复界面的问题。
- 标题栏统一使用 Tauri 原生拖拽与双击处理，减少 Windows 窗口消息竞态。
- 新增标题栏窗口交互回归测试。

### Markdown 关联文件图标

- 重新设计 Windows 资源管理器中的 Markdown 关联文件图标。
- 采用更简洁的白蓝文档轮廓、深蓝 `M` 与蓝青渐变箭头，提升视觉一致性。
- 优化 16px、24px、32px、48px、64px、128px 和 256px 下的辨识度。
- 本页全部安装包均由更新后的 v0.3.2 源码重新构建。

### 发布与文档

- 应用版本号升级至 v0.3.2。
- 完善 v0.3.1 与 v0.3.2 更新日志、安装提示和跨平台下载说明。
- GitHub Actions 生成 Windows x64、macOS Intel、macOS Apple Silicon 与 Linux x64 安装包。

## 安装提示

- **Windows：** 如果 SmartScreen 显示“未知发布者”，请先确认下载地址来自本 Release 页面，再选择“更多信息 → 仍要运行”。签名策略见 [Code Signing Policy](https://github.com/zhcx/markitdown/blob/main/CODE_SIGNING_POLICY.md)。
- **macOS：** 如果系统提示无法验证开发者，可在 Finder 中右键应用并选择“打开”，或在“系统设置 → 隐私与安全性”中确认打开。
- **Linux AppImage：** 下载后执行 `chmod +x MarkitDown_0.3.2_amd64.AppImage`，然后运行该文件。
