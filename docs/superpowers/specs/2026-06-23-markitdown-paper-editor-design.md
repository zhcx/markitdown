# MarkitDown 纸张式双主题 UI 设计

## 目标

将 MarkitDown 现有桌面 UI 统一为“纸张式编辑器”视觉语言，同时完整支持 light、dark 和 system 三种主题选择。改造参考 Light Theme Overview 的安静阅读感：暖白纸面、弱分隔、克制的珊瑚强调和清晰的文档层级。

本次改造保留现有的资源管理器、编辑器、预览三栏布局，以及所有编辑、预览、AI、设置、导出和文件操作功能。它不改变交互流程、组件数据、存储格式或 Tauri 后端行为。

## 设计原则

- 主题成对：浅色与深色共享同一套表面层级、间距、圆角和交互语义；dark 不是 light 的简单反色。
- 文档优先：编辑器与预览以轻量纸页呈现；应用 chrome、侧栏和工具栏退后成为低干扰支撑层。
- 强调克制：珊瑚色只用于当前选中项、主要操作、链接/焦点和有限的状态提示，避免整块高饱和填充。
- 功能不动：所有行为、键盘快捷键、拖拽、分栏拖动、设置和 AI 状态保持原样。

## 主题令牌

`src/styles/main.css` 继续作为唯一的主题入口。`App.tsx` 已将设置值解析后写入 `data-theme`，本改造只调整该属性下的 CSS 自定义属性，不添加新的运行时主题状态。

| 语义 | Light | Dark |
| --- | --- | --- |
| 应用工作区 | `#F5F2EC` | `#181A19` |
| 次级面板 / 侧栏 | `#F9F6F0` | `#1E201F` |
| 文档纸页 | `#FFFDF9` | `#272927` |
| 主要文字 | `#37322C` | `#EDE8DE` |
| 次要文字 | `#776F66` | `#B5AFA5` |
| 边框 | `#E8E2D8` | `#383A38` |
| 主强调 | `#C96B52` | `#DC846A` |
| 选中背景 | `#F5E4DE` | `#3A2722` |

阴影仅用于纸页、菜单、对话框和悬浮面板。圆角统一为 6 px（小型控件）、8 px（工具组/列表项）、12 px（工作区纸页和常规浮层）；不再使用会造成“卡片堆叠感”的大面积 16 px 圆角。

## 组件覆盖与边界

| 区域 | 视觉改造 | 保持不变 |
| --- | --- | --- |
| 菜单栏、标签栏、工具栏、状态栏 | 更低对比的 chrome、细分隔线、紧凑工具组、珊瑚主操作 | 菜单项、标签行为、工具栏命令、状态信息 |
| 资源管理器 | 哑光侧栏、简化树节点、低饱和选中态 | 文件树、展开状态、文件操作、可拖动宽度 |
| 编辑器与预览 | 共享安静工作区，各自呈现轻量纸页；加强阅读排版 | 编辑器、实时预览、可拖动分隔线、分栏模式 |
| Markdown 内容 | 标题、引用、代码、表格、图片遵循纸张阅读层级 | Markdown 解析、Mermaid、KaTeX、语法高亮功能 |
| 设置、导出、右键菜单 | 使用相同表面、边框、焦点和按钮规范 | 表单字段、保存/取消、导出流程、菜单动作 |
| AI 弹窗、校对面板、聊天侧栏 | 与主工作区相同的层级、提示色、输入框与气泡规范 | 请求状态、建议采纳、聊天数据和拖拽宽度 |

原生 Windows 标题栏仍由 Tauri 的 `decorations: true` 管理，不在本次 CSS 改造范围内。

## 实现结构与数据流

1. 在 `src/styles/main.css` 集中更新默认令牌和 `[data-theme="dark"]` 对应令牌，并清理与新规则冲突的局部颜色覆盖。
2. 以现有组件 class 为锚点，对 workspace、侧栏、编辑/预览、chrome 和浮层应用令牌化规则；不改动其 TypeScript props 或状态逻辑。
3. `useAppStore` 中的 `settings.appearance.theme` 保持现有职责：`App.tsx` 将 `light`、`dark` 或 system 解析结果写为 `data-theme`，浏览器通过 CSS 变量完整重绘。
4. 无效主题值继续由 `App.tsx` 回退至 `light`，因此新增 CSS 不引入错误路径或迁移需求。

## 验证与交付

- 手动检查 light、dark 和 system 三种模式：普通、悬停、选中、焦点、禁用、滚动条和文本选择状态均保持可读。
- 以空白文档和含标题、列表、代码、表格、引用、图片、数学公式的文档检查编辑器/预览。
- 打开设置、PDF 导出、上下文菜单、AI 翻译/校对/聊天，确认其表面层级和对比度与主界面一致。
- 执行 `npm run lint` 与 `npm run build`。
- 执行 Tauri Windows 打包，验证生成的 NSIS `.exe` 和/或 MSI 安装包能启动，并在浅深主题切换后正常工作。

## 非目标

- 不重新设计信息架构、三栏布局、窗口尺寸或原生标题栏。
- 不添加主题类型、配色选择器或新的应用设置。
- 不修改 Rust 命令、文件格式、AI API、图片上传、PDF 逻辑或自动更新流程。
