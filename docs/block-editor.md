# 兼容混合块编辑器

Zeditor 的块编辑器以 Markdown 为唯一保存格式。新建文档和现有 Markdown 文档都可以进入块模式：常见结构使用原生块，复杂扩展使用原始 Markdown 块保真承载。

## 当前支持

- 段落、一级至四级标题
- 无序列表、有序列表、待办列表
- 引用、代码块、分隔线
- 原生 GFM 表格，支持表头、数据行和列对齐
- 图片、链接、粗体、斜体、删除线和行内代码
- 在空块输入 `/` 打开 Slash 菜单
- 输入 `# `、`- `、`1. `、`- [ ] `、`> ` 或三个反引号时自动转换块
- 块悬停时显示手柄样式，支持顶层块复制、删除和拖拽

## 源码模式与安全降级

源码模式保留原有 Monaco 编辑器，适合需要精确控制整篇 Markdown 的场景。块模式不再因为扩展语法强制切换源码模式：无法安全结构化的内容会显示为可编辑的原始 Markdown 块。

Mermaid、公式、HTML、Details、脚注、视频宏、TOC 和未知扩展都会保留原始源码。原始 Markdown 块在编辑区只显示文本，不执行 HTML 或脚本；实际渲染继续由经过安全清洗的预览区负责。

## 保存、预览与备份

块编辑器每次有效编辑都会序列化为 Markdown，并沿用现有标签页 dirty 状态、时间线、本地保存、预览、WebDAV 和 S3 备份链路。不会生成 `.zdoc`，也不会维护第二份块数据副本。

WebDAV/S3 仍然只在本地文件保存成功后异步入队；云端失败不会阻塞本地保存。支持范围内的文档在块模式下可能被统一序列化为规范 Markdown 排版，但内容语义保持不变。

## 原始 Markdown 块

数学公式、Mermaid、HTML、Details、脚注、视频、TOC、数据库块、多列扩展和未知语法会作为原始 Markdown 块进入块模式。块内源码不转义、不格式化，保存后仍是标准 `.md` 文本；结构化块之间的空行会规范为统一排版。

## 可靠编辑与命令中心

块模式使用稳定的 ProseMirror 编辑宿主：React 只负责挂载节点，编辑器内部负责节点内容。普通输入支持 Enter 拆分段落、列表和任务项，Shift+Enter 插入软换行，Backspace 恢复空标题或代码块，Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z 和 Ctrl/Cmd+Y 提供撤销与重做。

编辑区会根据窗口宽度使用 20–48px 自适应横向留白，正文最大宽度约 980px。编辑器与预览通过源行锚点双向同步；当前预览块只使用 2px 侧线和约 5% 强调色底纹，已经在可视区内的块不会因光标移动被强制滚动。

在行首输入 `/` 可打开统一命令中心，命令按“基础块、格式、媒体、AI 写作”分组，支持中文标题、英文别名和方向键/Enter 导航。未配置 AI 时，AI 命令仍会显示并说明配置原因，不会执行。

没有选中文本时，AI 改写、翻译、校对、摘要和续写以当前块为目标；有选区时只处理选区。改写、翻译和摘要始终先进入 AI 差异确认框，确认后才写入，之后可用一次撤销恢复。

表格使用原生结构化编辑；公式、Mermaid、HTML、details、脚注、视频、目录和未知扩展使用原始 Markdown 块。只有块编辑器本身无法初始化时才显示可恢复提示并允许进入源码模式，当前文档内容不会丢失。
