# 兼容混合块编辑器

Zeditor 的块编辑器以 Markdown 为唯一保存格式。新建文档默认使用块编辑模式；现有 Markdown 文档如果只包含当前支持的基础语法，也会进入块模式。

## 当前支持

- 段落、一级至四级标题
- 无序列表、有序列表、待办列表
- 引用、代码块、分隔线
- 图片、链接、粗体、斜体、删除线和行内代码
- 在空块输入 `/` 打开 Slash 菜单
- 输入 `# `、`- `、`1. `、`- [ ] `、`> ` 或三个反引号时自动转换块
- 块悬停时显示手柄样式，支持顶层块复制、删除和拖拽

## 源码模式与安全降级

源码模式保留原有 Monaco 编辑器，适合需要精确控制 Markdown 的场景。含有表格、数学公式、Mermaid、HTML、Details、脚注、视频宏或其他暂不支持结构的文档会自动使用源码模式；块编辑器不会重写这些内容。

在源码模式下可以通过编辑器右上角切换按钮尝试进入块模式。只有能力检测通过时才允许切换。块编辑过程中如果工具栏、AI 或 Slash 插入了暂不支持的 Markdown，Zeditor 会先保留完整 Markdown，再切换到源码模式。

## 保存、预览与备份

块编辑器每次有效编辑都会序列化为 Markdown，并沿用现有标签页 dirty 状态、时间线、本地保存、预览、WebDAV 和 S3 备份链路。不会生成 `.zdoc`，也不会维护第二份块数据副本。

WebDAV/S3 仍然只在本地文件保存成功后异步入队；云端失败不会阻塞本地保存。支持范围内的文档在块模式下可能被统一序列化为规范 Markdown 排版，但内容语义保持不变。

## 当前不在块模式中的能力

表格、数学公式、Mermaid、HTML、Details、脚注、视频、数据库块、多列布局和多人协同暂时继续使用源码模式。后续增加这些能力时，需要同时扩展 Markdown 能力检测、块 schema、解析/序列化和源映射测试。
